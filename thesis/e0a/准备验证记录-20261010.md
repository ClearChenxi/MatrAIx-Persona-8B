## 发现与修正

官方提示加载器会二次按问卷 ID 查找内容，直接传入历史运行任务目录不足以保证活动事实进入提示。已在论文适配层加入临时内存任务映射，合成测试检查活动 context、行为字段和问卷身份完整进入消息，并确认映射恢复。官方源码未修改，原合成任务的默认行为保持兼容。

首版准备提交 `1e8b8e3397d0de35ab4e4436e2d5c1816ec4dd88` 已推送。推送后执行分支检查发现 Git 默认转义中文文件名，会误判论文文件为官方源码变更，并导致按文件名登记哈希失败。已在论文 Git 读取函数中关闭显示转义，新增真实仓库的中文路径回归检查；该检查只读代码路径、不读取家庭数据。修正版以独立提交备份，首版保留。

历史程序要求确认来源、干净实验分支、已备份提交和不变官方标签；只允许五张输入表，保存来源前后哈希与确定性抽样轨迹。历史问卷使用独立 ID；模型 digest/Ollama 版本须匹配方案；预算六次、首错停止、无修复生成。默认配置仍为待确认，不因合成测试通过而开放真实执行。
