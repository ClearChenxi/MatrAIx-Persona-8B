## 已验证配置

来源与版本：官方仓库 <https://github.com/MatrAIx-ai/MatrAIx-Persona-8B>；官方提交 `3633d8dab149a9482a71b024418a49ae828cc941`，MIT；固定标签 `thesis-upstream-3633d8d`。实验 Fork 与分支见 [资料与版本索引](资料与版本索引.md)。官方源文件保持不变，适配层在 `thesis/e0a/`。

实际模型 `qwen3.5:9b`，9.7B、Q4_K_M；完整 digest `6488c96fa5faab64bb65cbd30d4289e20e6130ef535a93ef9a49f42eda893ea7`。已验证 Ollama `0.33.3`、Python `3.12.13`、macOS `26.5.2`、arm64。已记录设备为 M4 Pro / 24 GB；未来每次运行重新捕获实际环境。

有效参数：temperature=0、seed=20261010、num_ctx=8192、num_predict=512、top_k=20、top_p=0.95、presence_penalty=0、think=false、stream=false、format=json、keep_alive=5m。官方客户端温度 0.7 被适配器显式映射为 0，这是论文配置差异。`openai/` 仅为兼容客户端路由别名。固定 seed 不保证跨设备重复。

输出为单个 `p_redeem` 十进制字符串，再严格解析为 [0,1] 数值。字符串保留零，避免官方自由文本归一化丢失数值零。拒绝错误问卷 ID、重复问题、额外理由/置信度、非有限或越界概率与截断；不修复、不补齐、不将失败记为零。

合成检查每条两次、共六次，无重试，首错停止。实际结果和证据位置见 [验收报告](验收报告-20261010.md)。这里只描述技术可用性，不证明校准、代表性、排序有效性或优于传统方法。

## 历史检查的拟议身份和接入

本轮使用本地 cohort `thesis-e0a-history-27-20x3-v1`、task `thesis_e0a_history_v1`。cohort 为开发活动 27 的有效参与家庭中，有窗口内正购买的家庭，以固定 SHA-256 顺序选择前20户，ID 仅保留在本地连接档案，不发送给模型。

家庭事实由只读 CSV 确定性聚合；活动事实由 campaign_desc/coupon/product 确定，不读取兑换表或人口表。真实输入、字段来源、时间规则、原始文件哈希及抽样轨迹保存到被 Git 忽略的本地准备包。精确词表、字段和正式重复次数尚不冻结为 E1 配置。

历史任务使用独立问卷 ID。由于官方提示构建会再次按 ID 查找任务，论文适配层临时将该 ID 的内存映射指向运行包的任务目录，渲染和执行结束后恢复映射，官方源文件不变。合成测试已验证活动 context 和家庭行为完整进入消息；这一适配差异须在真实运行 manifest 中记录。

执行须从已提交、已推送且干净的实验分支启动；逐次保存运行 manifest、实际消息、原始响应、解析状态、次数与失败，核对前后模型摘要。本轮用户批准预算为 20×3=60 次，首错停、不重试、不回退。正式 E1 的最大两次重试 / 历史基率回退与此小检查分开定义。
