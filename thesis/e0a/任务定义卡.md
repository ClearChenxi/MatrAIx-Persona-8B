# E0a 唯一主任务定义卡

版本 v1.0；日期 2026-10-10。对应执行手册阶段一、步骤 3。定义依据为当前蓝图、执行手册和 REVIEW_FIXES；E0b 审计及正式冻结尚未完成。

## 研究问题和预测任务

只使用投放前家庭行为和活动事实，所评估的 Persona 配置能否比 RFM 规则、Logistic 和 CatBoost 更准确地预测已确认收券家庭的真实兑换响应？不预设 Persona 胜出。各方法获得同一 X/S、面对同一活动和家庭、预测同一事件。

| 要素 | 唯一定义 |
|---|---|
| 数据 / 总体 | Dunnhumby；仅 campaign_table 中确认参与 Type B/C、收到完整券包的家庭 |
| 单位 | `(household_key, CAMPAIGN)`；一个家庭—活动，不能解释为某个家庭成员 |
| 预测截点 | 活动 START_DAY 之前；当天交易不属于投放前信息 |
| X 默认窗口 | `START_DAY−84 ≤ DAY < START_DAY`；历史活动结果只能来自权限允许且 `END_DAY < START_DAY` 的完整活动 |
| S | 类型、有效天数、唯一券数、商品/品类/部门/品牌类型覆盖及可证明规则；缺失券面金额、文案、图片、最低消费条件保持未知 |
| Y1 主标签 | 同家庭、同活动、有效 COUPON_UPC 且 `START_DAY ≤ DAY ≤ END_DAY` 的至少一次有效兑换为 1；日志 / 观察完整且无兑换才为 0 |
| 标签异常 | 重复去重；跨券/活动连接、超期、无参与、日期等异常留痕；不可确认完整标签的记录不可评价 |
| 主输出 | P1/B2/B3 声明或估计概率 `p_redeem∈[0,1]`；B1 确定性排序分数，不能伪装概率 |
| 输出事件 | 收到本活动完整券包后，在完整有效期内至少兑换一张有效券；不是购买、访问、利润或信心 |
| 信息限制 | 不编造年龄、收入、性格、动机；默认排除时点不明的人口表；家庭和活动 ID 仅作连接/审计 |

## 方法和评价

| 方法 | 角色 |
|---|---|
| P1 | 待审核的 MatrAIx-compatible domain persona agent，基于官方开源 Survey Agent / 本地模型配置 |
| B1 | RFM / 业务规则，固定排序；不计算 Brier 或 log loss |
| B2 | Logistic 回归，历史标签开发及 R 校准机会 |
| B3 | CatBoost 等强表格模型，同样历史标签与 R 校准机会 |
| A0 | 同基础模型、同 X/S 的普通 LLM 直接估计，检验工作流差异；若实际相同则合并并说明 |
| E1a | 无 Persona、错配 Persona，以及适用的精简 Persona、第二模型 / 等义模板复核 |

主指标为 Y1 的逐活动 Average Precision（AP）等权宏平均，不换成梯形 PR 曲线面积。P1−B1/B2/B3 构成三项主比较族。若有可辩护的对应推断，报告 Bonferroni 98.3333% 双侧区间；三项下界均 >0 才支持该推断范围内胜过全部预设传统基线。

当前候选 T 仅一个活动时间重叠连通块，**不能做伪独立活动 Bootstrap 或确认性跨活动外推**。默认主证据为探索性：逐活动差值、宏平均、方向与异质性。固定这些活动的家庭聚类配对 Bootstrap 10,000 次仅用于条件范围，AP 使用固定可识别活动集合；无效抽样 >5% 时不报告宏 AP 区间。

Brier / log loss 单列概率表现；P1 对 B2/B3 的 Brier 检验若报告则 Holm 校正。原始概率与 R 选择的校准版本分开；不在 T 上校准。所有 AP 用未校准主分数。log loss 固定裁剪至 [1e-6,1−1e-6]。top 10%/20%/30% 均报告，人数 floor(kN)，同一固定哈希打破同分。单类 ROC-AUC 为 NA，无正例 AP 不可识别，活动保留且报告共同分母。
