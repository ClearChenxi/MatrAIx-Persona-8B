# E0a 唯一主任务定义卡

版本 v1.3；更新日期 2026-10-11。对应执行手册步骤 3，并继承已验收的 E0a、E0b 和统一 D/R/T 数据事实。历史方法开发、E1a/E1b 技术门槛、正式冻结和 T 预测尚未完成。

## 四层研究框架与当前实验层级

全文保留四个研究层次：

1. Persona 分数是否包含真实响应信息；
2. Persona 是否比 RFM、Logistic 和 CatBoost 更有竞争力；
3. 差异是否来自 Persona 信息、表达或 Agent 工作流，而不是一般 LLM 能力；
4. 模型是否识别“什么活动适合什么人”。

当前 E1 只实施前三层。E1 是父实验，不另产预测；E1a“预测效度与传统方法竞争力”对应层次 1、2，E1b“Persona 增量价值与机制”对应层次 3。第四层保留为未解决问题，本轮不新增对应实验，也不能用 E1a/E1b 的响应预测结果代答。

## 共同预测任务

只使用投放前家庭行为 X 和活动事实 S，预测已确认收券家庭在完整有效期内是否至少兑换一张该活动的合法券。各方法面对同一活动、家庭和 Y1；不预设 Persona 胜出。

| 要素 | 唯一定义 |
|---|---|
| 数据 / 总体 | Dunnhumby；仅 campaign_table 中确认参与 Type B/C、收到完整券包且具有合法历史画像的家庭 |
| 单位 | `(household_key, CAMPAIGN)`；一个家庭—活动，不能解释为某个家庭成员 |
| 预测截点 | 活动 START_DAY 之前；当天交易不属于投放前信息 |
| X 默认窗口 | `START_DAY−84 ≤ DAY < START_DAY`；历史活动结果只能来自权限允许且 `END_DAY < START_DAY` 的完整活动 |
| S | 类型、有效天数、唯一券数、商品/品类/部门/品牌类型覆盖及可证明规则；缺失券面金额、文案、图片、最低消费条件保持未知 |
| Y1 主标签 | 同家庭、同活动、有效 COUPON_UPC 且 `START_DAY ≤ DAY ≤ END_DAY` 的至少一次有效兑换为 1；观察完整且无兑换才为 0 |
| 主输出 | 概率方法输出 `p_redeem∈[0,1]`；B1 输出确定性排序分数，不能伪装概率 |
| 输出事件 | 收到本活动完整券包后，在有效期内至少兑换一张有效券；不是购买、访问、利润、增量或信心 |
| 信息限制 | 不编造年龄、收入、性格、动机；家庭和活动 ID 仅作连接/审计，不进入模型或 LLM 消息 |

## E1a：预测效度与传统方法竞争力

| ID | 方法与角色 |
|---|---|
| N0 | D 历史总体兑换率常数；无个体、无活动差异 |
| N1 | 仅使用 S 的低容量活动级概率模型；不使用 X，同活动内分数相同 |
| B1 | RFM / 历史兑换业务规则；只评价排序 |
| B2 | Logistic，使用统一结构化 X/S，允许 D 训练和 R 校准 |
| B3 | CatBoost，使用统一结构化 X/S，允许 D 训练和 R 校准 |
| P1 | 已验收身份路径的 MatrAIx-compatible domain persona agent，基于官方开源 Survey Agent / 本地 Qwen 后端 |

层次 1 的固定比较为 P1-N0、P1-N1；层次 2 的固定比较为 P1-B1、P1-B2、P1-B3。主排序指标为 Y1 的逐活动 Average Precision 等权宏平均，不换成梯形 PR 曲线面积。测试活动真实基率只在解封后作为评价参考，不能进入 N0/N1。

若作固定测试活动条件范围内的比较判断，层次 1 两项 AP 差使用 Bonferroni 97.5% 双侧同时区间；层次 2 三项使用 Bonferroni 98.3333% 双侧同时区间。Brier/log loss 只比较 N0/N1/B2/B3/P1；若检验，P1 对其余四项使用 Holm 校正。AP、概率准确性和 top 10%/20%/30% 富集分别作答。

## E1b：Persona 增量价值与机制

| ID | 条件与唯一解释目标 |
|---|---|
| L0 | 只给 S 的直接 LLM；与 L1 的差检验客户事实整体价值 |
| L1 | 完整 X/S 的结构化直接 LLM；代表普通 LLM 使用相同事实 |
| L2 | 与 L1 相同事实的 Persona 文本直接 LLM；`L2-L1` 检验 Persona 表达 |
| P1 | 完整 Persona Agent；`P1-L2` 检验 Survey Agent 工作流 |
| P2 | 跨预设行为群体错配整套 X；`P1-P2` 检验正确客户—画像关联 |
| P3 | 仅保留冻结 R/F/M 与同一 S；`P1-P3` 检验丰富行为字段 |
| P4 | 在 L1/L2/P1/P2/P3 上更换预设第二基础模型；检验方向是否依赖单一模型 |

L0/L1/L2/P1/P2/P3 使用相同基础模型、事件、输出 schema、数值精度和失败规则。若 L2 与 P1 渲染后的实际模型消息相同，必须合并并声明不能识别 Agent 工作流。五项主要机制差 `L1-L0`、`L2-L1`、`P1-L2`、`P1-P2`、`P1-P3` 若作显著性判断，作为一个比较族使用 Holm 校正。P4 只作方向复核，不与主模型合并增加样本量。

只有 P1 优于 L1 且 P2 相对 P1 退化，才支持完整 Persona Agent 相对同事实直接 LLM 具有增量价值。只有 `L2>L1` 才能归因于 Persona 表达；只有 `P1>L2` 才能归因于 Agent 工作流；P1 只优于 L0 只能说明客户信息有用。

## E2：少标签增量与数据效率

E2 不新增研究层次，也不用于补救 E1。它固定检验在相同少量目标活动标签下，冻结 P1 分数是否为传统 B3 提供额外信息。主活动为 14、16、17、19、20、22、23、25，预算 n=0/10/20；活动 20、22、23、25 另作 n=40 敏感性。活动集合只由封存前权限规模确定。

E2-1 使用少量标签适配冻结 B3 分数；E2-2 在相同低容量框架中增加冻结 P1 分数；E2-3 改为增加冻结 B2 分数。唯一主比较为 E2-2 相对 E2-1 的八活动等权宏 Brier 差，n=10 和 n=20 分别报告。E1a/E1b 预测必须先封存，E2 全部预测再封存，之后才能开放最终评价标签。

## 技术启动门槛

E0a 的 20 户历史检查中，19 户三次均为 0，1 户三次均为 0.45；它只证明接口可运行，并提示分数退化风险。

正式 T 前，P1 在 R 的合法输出率必须不低于 99%，分数不得全相同；每个样本数不少于 20 条的 R 活动中至少出现 3 个不同合法分数，全部检查记录中任一单一分数不得占 90% 以上。温度 0、固定 seed 下完全相同的调用不算独立重复：确定性路径每条正式生成一次；随机路径使用至少 3 个预先固定的不同 seed，所有 LLM 条件使用同一 seed 集合，并要求各活动 seed 间最小 Spearman 与 top-30% Jaccard 均不低于 0.80。

未通过技术区分度时只能在 D/R 修正并重新完整检查；仍失败则停止 P1 的正式 T 预测并报告技术不可用，不得读取 T 后调整。

## 时间、权限与结论边界

E0b 已固定 D=27/28/29/1/2/3/4/5/6/7，R=9/10/11/12；活动 24 因结果窗不完整固定排除，最终可评价 T=14/15/16/17/19/20/21/22/23/25。统一输入为 D 729 条、R 681 条、T 1,714 条；T 按全局家庭权限分为 328 条适配记录和 1,386 条最终评价记录。T 标签、基率和正例数仍封存。

当前 T 仅一个活动时间重叠连通块，不能做伪独立活动 Bootstrap 或确认性跨活动外推。主证据为逐活动差、等权宏平均、方向和异质性；固定这些活动的家庭聚类配对 Bootstrap 只说明条件范围。

E1a 与 E1b 的全部预测必须先冻结并封存，之后才可按 E2 开放适配标签；E2 预测全部封存后才能开放最终评价标签。E1a/E1b 只能支持当前已收券家庭中的响应预测及机制结论，E2 只能支持少标签辅助价值；均不能声称营销因果增量、最佳发券对象、利润、ROI、替代真实试验、官方托管产品普遍有效或第四层活动—人群匹配。
