# E0a 重启任务定义卡

版本：2026-10-14 重启预执行版。研究问题、方法和结论边界遵循
`thesis/experiment-blueprint/` 的现行蓝图、执行手册与修订补充。

预测单位为已确认参与 Type B/C 活动的家庭—活动。预测时只使用活动
`START_DAY` 之前可见的家庭行为与活动事实。主结果 Y1 为家庭在活动完整
有效期内至少兑换一张属于该活动的有效券。P1 输出声明概率；N0/N1、
B2/B3 输出各自定义的概率或分数；B1 只输出排序分数。

E1a 比较 P1 与 N0/N1/B1/B2/B3，主排序指标是逐活动 Average Precision
的等权宏平均。E1b 在同一评价行上检验客户事实、Persona 表达、Agent
工作流、正确画像关联及字段丰富度。E2 使用固定适配权限和标签预算，
检验冻结 P1 分数对历史 B3 的额外价值。

E0a 的作用仅是验证官方开源 `PersonaJsonSurvey` 与 `HostEnvironment`
经本地 Ollama 适配后能接收限定事实、产生可解析响应并保存完整调用
证据。它不评价真实预测准确性。正式 P1 称为
`MatrAIx-compatible domain persona agent`，不得写成官方托管平台或
官方 Persona-8B 权重的结果。

本重启的 E0a、E0b、E1a/E1b、E2 尚未产生新的正式结果。旧实验 T
结果曾进入后续校准和报告；重新运行相同数据时，论文须披露这一历史
可见性。具体执行权限见重启决策记录和各阶段配置。
