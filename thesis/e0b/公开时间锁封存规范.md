## 机制与边界

使用drand League of Entropy主网Quicknet和官方`tlock/tle v1.2.0`。链哈希、BLS方案、公钥、3秒周期、模块版本及Go校验和固定在`timelock-policy.json`。只允许生产Quicknet。

该机制能证明密文在指定轮次前不能依正常协议解密，但不能追溯证明封存前从未看过或复制明文，也不能发现未纳入声明扫描根的秘密副本。副本程序可强制不同路径和不同介质标识，但介质标识由执行者声明，不能单凭程序证明两份副本物理独立。论文必须保留这些限制。

## 预测合同与日程

`prediction-contract.json`当前为`pending_protocol_freeze`。D/R开发后必须改为`registered`，逐项固定E1/E1a/E2的方法ID、变体/消融ID、T活动、预测池、重复次数、E2每活动适配预算、期望行数、分数列和唯一文件路径。E1/E1a必须覆盖全1714条T记录；E2只能预测1386条最终评价池中的登记活动。合同不完整时日程登记必须失败。

适配轮次至少比登记时的公开最新轮次晚7天，最终轮次至少再晚7天。日程只允许从两个轮次均为空的待登记状态执行一次。程序检查最新响应的新鲜度、`randomness=SHA256(signature)`，并用固定官方`tle`完成已到轮次的加解密探针；`tlock`内部使用drand库验证BLS签名。

```sh
.venv/bin/python thesis/e0b/register_timelock_schedule.py \
  2026-12-01T00:00:00Z 2027-01-01T00:00:00Z \
  --tle /path/to/tle-directory/tle
```

日期仅为格式示例。登记后必须先提交并推送策略。

## 封装、副本与明文检查

```sh

.venv/bin/python thesis/e0b/prepare_timelock.py \
  thesis/e0b/runs/e0b-20261011T033848.685233Z \
  /path/to/timelock-package --tle /path/to/tle-directory/tle
.venv/bin/python thesis/e0b/verify_timelock.py package \
  thesis/e0b/runs/e0b-20261011T033848.685233Z \
  /path/to/timelock-package/timelock-seal-manifest.json
```

创建两份不同路径、不同介质标识的副本。程序逐文件复制回临时目录并复算哈希：

```sh
.venv/bin/python thesis/e0b/create_timelock_replicas.py \
  /path/to/timelock-package/timelock-seal-manifest.json \
  /path/to/replica-manifest.json \
  --replica /path/on/storage-a thesis-disk-a \
  --replica /path/on/storage-b thesis-disk-b
```

副本通过后，再在另一次明确授权下处理明文。必须同时处理权威运行、`thesis/e0b/runs/`全部旧运行、数据解压目录和压缩包目录内的同哈希副本。权威路径不可读且声明扫描根中无可读同哈希副本后运行：

```sh
.venv/bin/python thesis/e0b/verify_timelock.py initial \
  thesis/e0b/runs/e0b-20261011T033848.685233Z \
  /path/to/timelock-package/timelock-seal-manifest.json \
  /path/to/replica-manifest.json
```

只有输出`public_timelock_seal_verified`才允许开始正式T预测。

## 预测冻结与公开时间证据

E1冻结清单必须与登记合同的E1/E1a制品集合全等；E2清单必须与E1/E1a/E2制品集合全等。核验器重算每个CSV的哈希、行数、方法、变体、活动、重复号、唯一行键和[0,1]分数；多一项、少一项或用无关文件代替都失败。

冻结清单推送到实验分支时，`.github/workflows/attest-prediction-freeze.yml`会自动为固定路径生成attestation。工作流成功后，用`gh attestation download <freeze-manifest> --repo ClearChenxi/MatrAIx-Persona-8B`保存bundle到模板登记路径。释放时用`gh attestation verify`校验制品哈希、仓库、固定工作流、源提交和Sigstore/GitHub透明日志时间。可回填的JSON时间和Git committer时间不再单独放行。透明日志见证时间不早于解锁时间时，该阶段永久判为预注册失败。

轮次到达后，`unlock_timelock.py adaptation ...`只能释放适配标签；`final_evaluation`只能在E2完整冻结和attestation验证后释放最终标签及四项源对象。
