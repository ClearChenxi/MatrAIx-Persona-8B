# e2_v2 — 少标签增量与数据效率（v2 重做版）

**状态**：骨架已建立。等 e1a_v2 / e1b_v2 主预测封存后才能跑——任务书 §23 严格要求"E1a 与 E1b 全部预测必须先封存。然后由保管方只开放当前预算的适配标签；最终评价 Y 继续封存"。

## 主比较族（任务书 §23 + §24）

| 条件 | 输入 | 后端 |
|---|---|---|
| **E2-0**（n=0 参照） | 冻结历史 B3，不适配 | 直接复用 `thesis/e1a_v2/methods/baseline_catboost.py` 的 D=729 训练结果 |
| **E2-1**（n=10/20） | 一维 Logistic 校准器，n 个适配标签上拟合 | sklearn Logistic |
| **E2-2**（n=10/20） | 同框架 + 冻结 P1 分数 | sklearn Logistic + e1a_v2/persona_workflow 输出 |
| **E2-3**（n=10/20） | 同框架 + 冻结 B2 分数 | sklearn Logistic + e1a_v2/baseline_logistic 输出 |

**主比较**：E2-2 − E2-1 在八个主活动（14 / 16 / 17 / 19 / 20 / 22 / 23 / 25）等权宏 Brier 差。**n=10 与 n=20 分别报告，方向一致才支持当前少标签范围内的稳定增量。**

## 活动 + 预算（任务书 §22）

- 主分析：活动 14 / 16 / 17 / 19 / 20 / 22 / 23 / 25 × n ∈ {0, 10, 20}
- 敏感性：活动 20 / 22 / 23 / 25 × n=40
- E2 主活动固定八活动（不因某方法表现改变）

## 关键约束

1. **不能从最终评价池补样本**——n 个预算完全来自适配池 328。
2. **校准器正则与特征转换**由 D/R 的小预算模拟任务预先确定，**不在 n 上另做调参**。
3. **单一类别 / 完全分离 / 拟合失败** → 回退冻结历史版本并报告；不能重抽标签直到同时有正负例。
4. **n=40 的四活动不与 n=10/20 的八活动连成同一学习曲线**。
