# 审查结论与实施补充

初版日期：2026-10-09；E1 层级修订日期：2026-10-11。适用于当前 README 的 Dunnhumby 主实验。

**优先级说明**：第 1--7 节保留原审查依据；与 2026-10-11 后已验收事实或第 8 节冲突时，以第 8 节、v1.1 执行手册和当前任务定义卡为准。尤其是旧“E1 主预测/E1a 消融”编号与固定三重复规则已被替代。

**结论：可以作为毕业论文的应用设计，但证据范围是“已收券家庭的活动响应预测”，辅以随机邮件数据的策略评价。不能据此声称完整营销创意、最优优惠券分配或 ROI 已得到验证。** 本补充落实审查修订；README 的研究方向保留，以下细节需纳入实际冻结配置。

## 1. 数据隔离与观察时点

先保存文件哈希，由隔离准备模块按活动日期、家庭 ID 和 X/S 生成划分，再开放开发/验证标签。锁定测试活动的响应率摘要同时封存；前期完整性审计只发布预设的缺失、非法值和一致性异常计数，不能把测试兑换率作为模型选择信息。

X 默认使用 `START_DAY-84 ≤ DAY < START_DAY` 的历史交易；当天交易不算投放前事实。过往活动兑换率只使用 `END_DAY < START_DAY` 的完整已结束活动。人口属性若没有可证明的记录时点，不声称其在活动前已知；主分析可排除，另作敏感性对照。

训练活动的 END_DAY 必须早于验证开始；开发/验证活动的 END_DAY 必须早于最早测试活动 START_DAY。跨边界活动作为 embargo 排除并计数，不能因其开始早就使用尚未结束时不可获得的完整结果。

只纳入 campaign_table 中参与 Type B/C 的家庭；未记录参与的家庭不是“收到但没兑换”负例。家庭是模拟/观测单位，不能解释成某位家庭成员的个人心理。未来未收券人群的投放效果不可由此识别。

主标签 `Y1=1` 当且仅当 coupon_redempt 有同家庭、同活动、同有效券 UPC 且 `START_DAY ≤ DAY ≤ END_DAY` 的至少一次记录；观察窗完整而无记录时记 0。重复记录先去重，日期/券连接冲突列异常。次标签目标商品集合须由预测前 coupon/product 表固定，不用测试期兑换反推；购买、退货、净额与消费金额口径在开发数据上冻结。

## 2. 指标与可证伪判据

主结果固定为 Y1；所有方法共用的主排序指标固定为每活动 Average Precision（AP）的等权宏平均，明确采用 AP 的定义，不能在 ROC-AUC/PR 曲线面积/top-k 之间挑测试上最有利的指标。

P1 对 B1/B2/B3 的 3 个 AP 配对差构成主比较族，分别报告 Bonferroni 98.3333% 双侧区间；只有三项下界均 >0 才称“主排序指标优于全部预设传统基线”。P1 与 B2/B3 的 Brier 差单列为概率评价族，若作显著性判断用 Holm 校正。AP 优势不等于概率校准优势；B1 没有概率输出，不计算其 Brier/log loss。

top 10%/20%/30% 响应率均完整报告，按固定哈希打破同分；选择人数统一为 `floor(k*N)`。log loss 计算时概率裁剪到 [1e-6,1-1e-6]，不在测试数据上校准。只有一种结果类别时 ROC-AUC 记 NA；无正例时 AP 标为不可识别，保留该活动和可算指标，报告有效活动数，不能静默删去。

这些排序结果只反映历史已收券家庭中的真实富集。不能据此声称“只给 top-k 发券会提高增量购买”或将高响应家庭等同受活动影响最大的家庭。

## 3. 活动与家庭的推断范围

保留 README 的活动级主分析，逐活动报告配对差和等权宏平均；时间相邻活动及同一家庭跨活动复现可能相关，不能把普通独立活动 Bootstrap 当作自动有效。

E0 在不读取测试 Y 的前提下，根据活动间隔/重叠冻结时间块及重采样方法；源验证阶段检查区间覆盖/精度。若独立时间块太少而无法支持活动层区间，则主报告效应量、逐活动异质性与不确定性，并声明探索性证据，不以数千家庭弥补跨活动重复不足。

另做固定这些测试活动的家庭聚类配对 Bootstrap：抽中某家庭时，其所有测试活动记录共同进入全部方法，10,000 次，不重新训练模型。该补充区间不能代表未来任意活动的外推不确定性。两个范围分开报告，不按哪一个显著挑结论。

## 4. E2 的准确定位与标签预算

E2 改称“回溯式当前活动标签预算检验”。完整活动期响应在 END_DAY 前不可知；开放同活动部分家庭的完整标签不能当作真实上线前小试投，除非另有先试投后正式投放的时间证据。

测试活动家庭先以固定 seed `20261009` 按全局家庭 ID 分成 20% 适配和 80% 最终评价，同一家庭在所有测试活动中保持权限。E1a/E1b/E2 在同一最终评价家庭集合上比较。E1a 与 E1b 预测全部先封存，再按冻结流程开放 E2 适配标签，不回改 E1a/E1b。

每活动候选预算修订为 n=0/10/20/40。适配家庭按与 Y 无关的固定哈希顺序先建立互不转换的训练/验证子池，再在两池中分别嵌套取 `floor(0.8n)` 与 `n-floor(0.8n)`；验证标签计入 n。不足预算的活动记不可执行，不能从最终评价家庭补充。学习曲线同时报告各 n 的活动组成，并在 n=10/20/40 共同可用活动子集比较，防止组成变化造成假增益。

## 5. Persona、普通 LLM 与输出精度

若使用官方运行时/模型，保存仓库提交或模型版本、persona/cohort schema、task/verifier 配置及原始调用日志；仅提示词仿照官方思路时称 MatrAIx-compatible。格式合法/画像遵循不是外部有效性证明。

最低对照增加“同 X/S 的普通 LLM 直接概率估计”，用于区分官方 agent 工作流与普通 LLM 提示。若 P1 本身就是普通 LLM 的同一概率提示，则两者合并，并明确不能识别 agent 工作流的附加价值。若要声称重复模拟行动有独特优势，须另有同信息的二元行为模拟聚合对照；当前概率输出本身不支持这种声称。

P1 概率输出是模型声明概率，尚未校准。重复规则以第 8.4 节为准：确定性配置每条正式生成一次；只有真实随机路径才使用至少 3 个预先固定的不同 seed，并让相关 LLM 条件共用 seed 集合。随机路径报告排序相关、top-30% 名单 Jaccard 与成本；常数或高度集中的分数不能算稳定性达标。未达标时只可在 D/R 增加预设 seed 数、修正技术配置或声明不可用，不能挑效果最好的 seed。对照无优势或退化也必须保留。

超时/非法输出最多重试 2 次；保留失败。最终无合法概率时回退至历史开发/验证集基率，不能用当前活动基率。合法率低于 99% 或某群体集中失败应作为技术问题报告，不能记作不兑换。成本按家庭-活动数 × 重复 × 方法/模板/模型数计，另列精度试跑与重试预算。

## 6. Hillstrom 辅助任务的精确定义

当前 E3 的主设定采用历史监督学习比较，D/R/T 按处理分层为 20%/40%/40%，seed `20261009`；D/R 的 M/W/0 标签均可用于训练，T 结果封存。它与历史协议的零目标标签冷启动实验不同，不能套用历史协议的 E1 编号或标签权限。

传统模型分别估计 M/W/0 响应，P1 同样对三动作独立给出两周访问分数。每方法选预测最优邮件，并按邮件相对 0 的增量分数固定覆盖 30%，即 `floor(0.30*N_T)` 人；其他人不发邮件。规则用固定品类/RFM 排序，不能叫增量概率。个体/群体粒度在冻结时统一；10%/20% 为次要预算。

另报只向正分数组投放、最多覆盖 30% 的决策策略；它与固定 30% 策略分开，避免把“少发邮件”优势当作排序优势。自然访问可能发生，无邮件分数不能固定为 0。

随机机制与 e 经核验后，在完整 T 上用 `Vhat(pi)=mean[1(A=pi(X))*Y/e(A)]`；visit 为主，conversion/spend 为次要。所有方法的差值在同客户上配对；按已核验分配层与 A 保持层人数重采样 10,000 次，SNIPS 为次要近似检查。不能先删不匹配行却使用原处理概率，也不能在随机化未确认时假设 e=1/3。

P1 对规则/Logistic/CatBoost 的 3 项另成 Bonferroni 比较族，与主 E1 分开；不发邮件比较单列。报告实际覆盖、动作一致样本数和 `ESS=(sum w)^2/sum(w^2)`，其中 `w=1(A=pi(X))/e(A)`。这些是评价支持度，不能称个体最优方案命中数。E3 的优势仅属于此邮件任务，不能证明 Dunnhumby 活动的因果收益。

## 8. 2026-10-11：E1 子实验与前三层证据修订

### 8.1 实验层级与范围

全文保留四个研究层次：预测有效、相对更好、Persona 增量价值、活动—人群匹配。当前只实施前三层；第四层暂缓，不新增实验实体，也不由当前响应预测替代回答。

E1 是父实验，不另产预测。E1a 是“预测效度与传统方法竞争力”，对应层次 1、2；E1b 是“Persona 增量价值与机制”，对应层次 3。原文件中的“E1 主预测”整体转为 E1a，原“E1a 消融”按下述可识别对比重构为 E1b。E2 少量标签适配和 E3 Hillstrom 扩展的既有定位暂不改变。

### 8.2 E1a 的固定方法和判据

E1a 必须包含 N0（D 历史总体常数）、N1（仅 S 的活动级概率模型）、B1（规则排序）、B2（Logistic）、B3（CatBoost）和 P1（完整 Persona Agent）。N0/N1 用于回答 P1 是否存在超出无个体预测的外部信号；B1/B2/B3 用于回答相对传统方法的竞争力。

层次 1 的 AP 对比族为 P1-N0、P1-N1；如作条件范围内判断，使用 Bonferroni 97.5% 双侧同时区间。层次 2 的 AP 对比族为 P1-B1、P1-B2、P1-B3，沿用 Bonferroni 98.3333% 双侧同时区间。当前 T 只有一个时间重叠连通块，所有区间和结论仍受原第 3 节限制，不能升级为确认性跨未来活动证明。

概率族为 P1 相对 N0/N1/B2/B3 的 Brier 差，若检验使用 Holm 校正。测试活动真实基率只在解封后作为 AP 和富集参考，不能成为 N0/N1 输入。AP 更好与概率更准分别作答。

### 8.3 E1b 的固定条件和唯一解释

E1b 必须在同一评价行和同一基础模型上包含：L0（只给 S 的直接 LLM）、L1（完整 X/S 结构化直接 LLM）、L2（同事实 Persona 文本直接 LLM）、P1（完整 Persona Agent）、P2（跨预设群体错配整套 X）、P3（精简 R/F/M Persona）和 P4（第二基础模型复核）。

主要机制对比固定为 L1-L0、L2-L1、P1-L2、P1-P2、P1-P3。它们分别只解释客户事实、Persona 表达、Agent 工作流、正确画像关联和丰富字段。P1 仅优于 L0 不能证明 Persona 或 Agent 有增量；L2 与 P1 渲染后的实际模型消息相同时必须合并，不能制造工作流差异。若对五项机制差作显著性判断，作为一个族使用 Holm 校正。P4 只作方向复核，不与主模型合并增加样本量。

### 8.4 生成重复、分数退化和启动门槛

旧第 5 节“每家庭初设 3 重复、3 个独立批次”不再自动适用。温度 0、固定 seed 和相同环境下完全相同的调用属于确定性复现，正式主配置每条只需一次，不能把多个相同文件当作新增证据。只有选择真实随机路径时，才使用至少 3 个预先固定的不同 seed，并让所有相关 LLM 条件使用相同 seed 集合后取均值。

P1 在 R 的合法输出率必须不低于 99%，分数不得全相同；不少于 20 条的 R 活动中至少出现 3 个不同合法分数，全部检查记录中任一单一分数不得占 90% 以上。随机路径另要求各活动 seed 间最小 Spearman 与 top-30% Jaccard 均不低于 0.80。区分度门槛只排除技术退化，不证明预测准确。未通过时只能在 D/R 修正并重新完整检查；仍失败则停止 P1 的正式 T 预测并报告技术不可用。

### 8.5 封存与机器编号

E1a、E1b 是需要完整枚举和封存的两个预测集；父级 E1 不另登记制品。E1a/E1b 全部冻结后才允许按 E2 决定释放适配标签。现有机器合同仍处于 `pending_protocol_freeze`；执行者必须在正式登记前将旧预测集命名与本层级对齐，并通过既有核验，不能仅修改说明文字后继续使用旧方法集合。
