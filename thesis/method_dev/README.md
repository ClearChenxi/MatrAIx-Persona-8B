# D/R 方法技术试跑

本目录只用于 E1a/E1b 正式 T 预测前的 D/R 技术试跑。程序硬性拒绝读取任何 T 文件；试跑不产生正式 T 预测制品，也不改变预测合同。

当前试跑固定为：D 使用统一输入阶段已经按 X/S 冻结的 20 条边界样本检查三个提示候选的接口、格式和分数；R 中 100 条按活动和冻结行为群体分层的哈希样本用于技术验收。主模型为本地 `qwen3.5:9b`，温度 0、`think=false`、上下文 8192、最大输出 64 tokens。正式提示须在 D 上按逐活动宏 AP 选择，平局优先简单版本；若边界样本的 AP 不可识别，本轮只能把最简提示用于 R 技术检查，不能声称提示已冻结。R 只用于最终合法率、区分度和稳定性记录。

运行示例：

```sh
python3 thesis/method_dev/run_dr_pilot.py --run
```

输出目录位于 `thesis/method_dev/runs/`，包含固定抽样、提示版本、请求/响应日志、原始预测和技术摘要。D/R 标签仅用于本地评价，不上传 GitHub。
