# E1 D/R/T字段字典

冻结日期：2026-10-11。机器可读完整版保存在权威运行的`public/field_dictionary.json`，逐字段记录来源、窗口、单位、缺失、传统模型编码和Persona呈现规则。正式输入包含56个X/S特征，`row_id`仅用于本地表间连接，不是模型特征，也不进入Persona payload。

| 字段组 | 字段 | 定义与口径 | 缺失/编码 |
|---|---|---|---|
| R/F/M | recency_days、basket_count、shopping_day_count、sales_total、average_basket_sales | 每活动START_DAY前84天合法正购买；购物篮和购物日去重 | 均为数值；只在D拟合缩放 |
| 记录质量 | positive_line_count、return_line_count、zero_sales_total_flag、product_taxonomy_missing_flag | 正购买行、非正数量行和结构缺失标志 | 计数或0/1；退货行不进入正购买金额 |
| 折扣行为 | retail_discount_basket_share、coupon_discount_basket_share | 合法正购买篮中相应折扣列非零的比例 | 六位小数；不解释为心理价格敏感性 |
| 历史活动 | prior_completed_campaign_count、prior_redeemed_campaign_count、prior_redemption_rate、no_prior_campaign_flag | 当前活动开始前已结束且权限允许的E0b合格D/R活动 | D只用更早D；R只用D；T只用D/R；无历史保留缺失 |
| 部门 | department_spend_shares_json | 84天正购买金额的部门占比 | 29项D词表加`<OTHER>`；结构化展开 |
| 品类偏好 | top_commodity_1--3及share、other_commodity_share | 按金额降序，类别名并列时按字典序 | D词表295项；R/T新类映射`<OTHER>` |
| 品牌类型 | brand_type_spend_shares_json | National、Private实际值的金额占比 | 不解释为具体品牌或忠诚度 |
| 活动属性 | campaign_type、valid_days、唯一券/商品数、部门/品类/品牌类型数 | campaign_desc、去重coupon-product关系和product | 活动ID不进入输入 |
| 活动构成 | 部门/品牌类型权重、前8券-品类权重、其余品类权重 | 按去重券-类别对计权，不按商品行数或兑换量放大 | D词表；六位小数 |
| 家庭-活动匹配 | target_product_sales_share、target_commodity_sales_share、target_product_recency_days、no_target_product_purchase_flag | 固定活动目标集合与84天历史交易匹配 | 无目标商品购买时recency缺失并显式标记 |

合法正购买固定为`QUANTITY > 0`、`SALES_VALUE >= 0`、BASKET_ID非空且PRODUCT_ID可连接。窗口为`START_DAY-84 <= DAY < START_DAY`，活动当天绝不进入历史。人口表和causal表不使用。家庭ID、活动ID、split、E2权限、行为分群、Y1和Y2均禁止进入模型特征。

无标识Persona payload与`line_number -> row_id`索引分开保存；payload只含观测行为、活动事实和明确的未知项，不包含row_id、家庭ID、活动ID、标签、人口、心理、动机、券面金额、文案、图片或最低消费条件。
